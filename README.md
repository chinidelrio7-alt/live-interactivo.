# Live Interactivo

Primera demo web de un tablero con fichas/avatares que se pueden agregar y arrastrar.

## Cómo probarlo
Abre `index.html` en un navegador moderno.

## Importante
Esta versión funciona localmente. No está conectada a TikTok LIVE, no lee comentarios ni recibe regalos/eventos reales. Esa integración requiere una arquitectura aparte y cumplir las reglas de edad y uso de la plataforma.
